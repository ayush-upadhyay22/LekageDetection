# Aperture — water leakage detection

This GitHub page is the **source code**, not the live website. GitHub always shows this README on the repository.

**Open the website here:**  
https://ayush-upadhyay22.github.io/LekageDetection/

## Local preview

```bash
npm install
npm run dev
```

Then open http://127.0.0.1:3000

## Deploy

Pushes to `main` build the static site and publish it to GitHub Pages. In the repo go to **Settings → Pages** and set **Source** to **GitHub Actions** if the site URL 404s on the first deploy.
